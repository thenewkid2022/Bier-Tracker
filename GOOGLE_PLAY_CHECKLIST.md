# ✅ Google Play Store Checkliste

## 🎯 **Vor der Veröffentlichung**

### **App-Entwicklung** ✅
- [x] Android-Build erfolgreich (AAB)
- [x] Material Design implementiert
- [x] Alle Features getestet
- [x] App läuft stabil

### **Google Play Console** ⏳
- [ ] Google Play Developer Account erstellen (25$)
- [ ] App-Listing erstellen
- [ ] App-Informationen eingeben
- [ ] Kategorie wählen (Produktivität)
- [ ] Altersfreigabe festlegen (3+)

---

## 🖼️ **Screenshots & Assets**

### **Screenshots erstellen** ⏳
- [ ] Hauptbildschirm (Getränke-Auswahl)
- [ ] Admin-Bereich (Benutzerverwaltung)
- [ ] Kaufprozess (Mengenauswahl)
- [ ] Profil-Übersicht (Guthaben)

### **App-Icon** ⏳
- [ ] 512x512 PNG Icon
- [ ] 1024x1024 PNG Icon
- [ ] Adaptive Icon für Android

## ⚙️ **Technische Vorbereitung**

- [ ] Google Cloud Console Projekt erstellen
- [ ] Service Account mit Play Console Admin Rolle
- [ ] JSON-Schlüssel herunterladen
- [ ] `google-service-account.json` im Projekt platzieren

### **EAS Submit konfigurieren** ✅
- [x] `eas.json` aktualisiert
- [x] Submit-Profile konfiguriert
